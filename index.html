Ranking Shorts Uploader

Ranking Shorts Uploader is a small personal tool. It creates short explainer videos and sends them to the operator's own TikTok account as drafts. The operator reviews each draft and publishes it manually inside the TikTok app. It is not a public service: only the operator's own account is connected, and no other users can sign up.

How it works

  1. The operator signs in once with TikTok (Login Kit, scope user.info.basic) using the button below.
  2. TikTok shows its consent screen. After approval, TikTok sends the operator back to this site (/callback/), which displays the sign-in address so the operator can finish the connection.
  3. When a new video is ready, the tool uploads it to the operator's TikTok inbox as a draft (Content Posting API, scope video.upload).
  4. The operator opens the draft in the TikTok app, adds the description and the AI-generated content label, and publishes it.
Operator sign-in

Requested permissions: user.info.basic and video.upload. Nothing is posted without the operator's manual review in the TikTok app.
