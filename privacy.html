Privacy Policy

Last updated: 24 November 2026

1. Who is responsible

The Tool is operated by an individual (the Operator, github.com/LeonHois). It is used only with the Operator's own TikTok account.

2. What data is processed

  • TikTok authorisation tokens (access and refresh token) that TikTok issues after the Operator signs in. They are used only to send the Operator's own videos to the Operator's own TikTok inbox.
  • Basic profile information (scope user.info.basic) as provided by TikTok during sign-in. It is not stored beyond what the sign-in itself requires.
  • Video files that the Tool creates itself. They contain no personal data of third parties.

3. Storage and security

The refresh token is stored encrypted in a private repository and can only be read together with a secret that is kept in GitHub Actions secrets. This website itself does not store, log or send any data: the page used after signing in only displays the address in your own browser.

4. Sharing

No data is sold, shared with third parties or used for advertising or profiling. Data is only exchanged with TikTok (to sign in and upload) and with the Operator's hosting provider GitHub (to run the Tool).

5. Retention and revoking access

Tokens are kept as long as the connection is needed. The Operator can revoke access at any time in the TikTok app under the account's connected apps and permissions, and can delete the stored token from the repository.

6. Contact

Questions or requests about data: github.com/LeonHois.
